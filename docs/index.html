Features

  • Encrypt/decrypt files (public-key or passphrase), multi-recipient (v2)
  • Encrypt/decrypt text directly from the GUI
  • Key generation, public key extraction, and key information
  • Detached signatures (sign and verify)
  • Inspect encrypted messages
  • Drag & drop support
  • Background processing to keep the UI responsive
  • Atomic file writes
  • 100% compatible with the tesseract-crypt CLI
  • Windows GUI subsystem by default (no extra console window)
