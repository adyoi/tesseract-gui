Features

  • Encrypt/decrypt files (public-key or passphrase), multi-recipient (v2)
  • Encrypt/decrypt text
  • Key generation, public key extraction, key info
  • Detached signatures (sign/verify)
  • Inspect messages
  • Drag & drop, background threads, atomic writes
  • 100% compatible with tesseract-crypt CLI
